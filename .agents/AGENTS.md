# Règles du projet — Carnet de Recettes

## Git Workflow

- Après chaque série de modifications terminée et validée par l'utilisateur, effectuer automatiquement :
  1. `git add -A`
  2. `git commit -m "<message descriptif>"`
  3. `git push`
- Utiliser des messages de commit descriptifs en français.
- Sur PowerShell, séparer les commandes avec `;` (pas `&&`).
